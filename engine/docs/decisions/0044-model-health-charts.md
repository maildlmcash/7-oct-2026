# 0044 — Model health and calibration charts

Status: accepted for caller-supplied calibration bins and labeled health charts. Brier, log loss, and drift are not calculated. No spot model is registered.

## Context

TASK 10.B.02 asks for calibration and reliability curves, Brier and log-loss history, drift, feature freshness, feed gaps, and model and data version. The chart must label the observed data window and the sample size. Known fixtures must match expected bins. A low sample must be visibly marked insufficient.

Design page 8 names predicted probability buckets versus observed outcome, a Brier score, a reliability curve, and log loss. It does not write the Brier or log-loss arithmetic, the bucket edges, or a minimum sample size. Design page 1 names model version, feature version, and the raw-data window. Design page 9 names model drift and data gaps as kill triggers and gives no drift statistic. `services/spot-book-sync.mjs` already records the reason `sequence gap`. Phase 11, which defines labels and the baseline model, has not been pasted. This tree has no prediction score.

## Decision

`services/model-health-charts.mjs` reads one of six views: calibration, brier/log-loss, drift, feature freshness, feed gaps, and model/data version. It does not read the other views in the same call.

Calibration uses the design comparison of predicted probability buckets with observed outcome. The caller supplies edges that start at 0, end at 1, and rise strictly. Missing or invalid edges return `bins are not configured` and no invented buckets. Lower buckets are half-open. The last bucket includes 1. A sufficient bucket reports the mean predicted probability and the observed rate as a reduced decimal or fraction. The source names no rounding scale. A bucket whose count is below the caller-supplied minimum sample size is `insufficient`, and its rate and mean stay null. They are not written as zero. An empty bucket stays insufficient. A missing minimum returns `sample size is not configured` and withholds every rate. Outcomes are only `0` or `1`.

Brier, log loss, and drift stay formula `NOT IN SOURCE`. History points are displayed only when the caller supplies them. The history bound is required. Stale input publishes no points. Feature freshness shows the integer age from the watermark to the observed time. A missing threshold returns `freshness threshold is not configured` and does not call the feature fresh. Age above a supplied threshold, or a negative age when a threshold is present, is stale. Omitted feed gaps return `feed gaps are not measured`. A supplied gap is labeled, including the existing reason `sequence gap`. The chart does not detect gaps and does not call the book sync. Missing model or data version returns `model version is not configured` or `data version is not configured`.

Every result labels `sampleSize` and `observedWindow` when those values exist. `direction` is null and `guaranteesDirection` is false. The Predictions section mounts the charts only while Predictions is selected. Nothing is read until a button is pressed. The shell has no observations, so calibration shows sample size 0, `bins are not configured`, and `insufficient`. Every width uses one column. Widths 375, 768, and 1280 remain fixtures. No eighth section, chart library, socket, or order function was added. Decision 0045 records the feature-definition version used for replay and does not change these charts.
